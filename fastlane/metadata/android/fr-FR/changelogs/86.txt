- Basé sur RustDesk 1.5.0, avec ses correctifs de stabilité et d'audio.
- Nécessite Android 7.0 ou version ultérieure.
- Identifiants enregistrés chiffrés avec une clé conservée dans l'Android Keystore.
- Mot de passe local facultatif pour protéger les paramètres.
- Si le PC distant l'exige, la session affiche un filigrane avec technicien, heure et code de session.
- Propose d'activer le mode confidentialité à la connexion ; désactivable.
