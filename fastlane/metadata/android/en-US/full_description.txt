ClantoDesk is Clanto Services' remote desktop and technical support application, based on the open-source RustDesk project.

Use your Android phone or tablet to connect to authorized Windows, macOS and Linux computers, view their screen and control mouse and keyboard input. Android devices can also receive remote assistance when the user explicitly starts the service and grants the required permissions.

File transfer works in both directions. When sending a file from Android, ClantoDesk opens the system document picker so you choose exactly which files to share, including files offered by cloud providers. Files received from a computer are published in the Download collection. ClantoDesk does not request unrestricted access to all files on the device.

When Android remote control is enabled, ClantoDesk uses AccessibilityService only to reproduce authorized remote touch, scroll and keyboard actions. The app shows a dedicated disclosure and asks for explicit consent before opening Android accessibility settings. Accessibility is not used for autonomous actions, advertising or data collection.

Connections use the Clanto rendezvous, relay and API infrastructure configured in the official build. Available session features include remote control, file transfer, clipboard synchronization, audio, chat, terminal and port forwarding when supported by both devices and allowed by their administrators.
